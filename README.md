# StockPilot

A PHP and MySQL-based inventory management system designed to simplify product, stock, sales, and supplier management.

## Features

- User authentication and role management
- Product management
- Category management
- Supplier management
- Inventory tracking
- Stock-in and stock-out management
- Sales processing
- Sales history and invoices
- Daily and monthly sales reports
- Discount management

## Technologies Used

- PHP 8.3
- MySQL 8
- HTML5
- CSS3
- JavaScript

## Installation

1. Clone this repository.
2. Create a MySQL database named `stockpilot_db`.
3. Import the database SQL file.
4. Configure your database connection in `config/database.php`.
5. Start your PHP development server.
6. Open the project in your browser.
